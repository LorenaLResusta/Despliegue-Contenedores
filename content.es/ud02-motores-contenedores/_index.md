# UD02 · Instalación y configuración de motores de contenedores

Ya sabes qué es un contenedor; ahora toca **trabajar con ellos como un profesional**. Instalas Docker Engine desde el repositorio oficial, comparas con Podman y containerd, gestionas el ciclo de vida completo, construyes imágenes optimizadas con Dockerfile y *multi-stage*, montas un registro privado y defines aplicaciones de varios servicios con Docker Compose. Al terminar, MiTienda funciona entera con una sola orden.
